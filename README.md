# 楓湖 · Maple Lake

互動楓林湖泊音景，以原生 HTML、Canvas 與 Web Audio 建構。

包含日夜循環、流動雲層、雨絲與湖面漣漪、隨風搖曳的楓樹、夜晚點燈的湖畔木屋，以及依天氣飛離／返回的水鴨。鳥類各自調整音量與出現頻率，灰背鴉叫聲依飛行位置切換聲道。使用者模式可透過麥克風低門檻觸發風、高門檻觸發雷；頻繁雷鳴會逐漸轉成下雨。

## 使用

開啟網頁後點擊「開啟自然音景」。瀏覽器需要使用者操作才能播放音訊。麥克風互動需要 HTTPS 或 localhost 與麥克風權限。

## 音效

雨聲、珠頸斑鳩、灰背鴉與蟋蟀實錄採 CC0 素材；作者、來源及授權紀錄見 [assets/LICENSE.txt](assets/LICENSE.txt)。斑鳩錄音包含其他鳥類背景聲，蟋蟀實錄的確切物種未鑑定。麻雀與合成蟋蟀是類群聲音模擬；風、樹葉及雷聲由 Web Audio 合成。
